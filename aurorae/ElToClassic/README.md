# aurorae/ElToClassic (CONCEPT / SPIKE, not a design)

UNVERIFIED until the VM run. Aurorae SVG window decoration: ElTo-colored titlebar (cream, deep green frame, rounded top corners)
with pill buttons. Buttons are yellow (minimize), green (maximize/restore) and blue (close).

Colors live in ../../palette/elto-palette.json only. Change it, then run `python3 palette/gen.py`
to regenerate the SVGs and the title text colors in ElToClassicrc. Do not edit the SVGs by hand.

Install: copy this folder to ~/.local/share/aurorae/themes/ElToClassic, then pick it in
System Settings > Window Decorations (kcm_kwindecoration), Aurorae section. Screenshot it.

Own SVGs, no third-party assets. Layout values are first guesses and may need tuning in the VM.
