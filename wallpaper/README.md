# ElTo default wallpaper (original, UNVERIFIED)

`elto-default.svg` is generated from `palette/elto-palette.json` by `python3 wallpaper/wallpaper.py`. Original artwork, no third-party assets. Edit the palette and rerun to recolor.

Set it in KDE: System Settings > Wallpaper > Add Image, or `plasma-apply-wallpaperimage wallpaper/elto-default.svg`.
